# *C. elegans*–PA14 Infection Transcriptomics

**Bioinformatics analysis of host transcriptional responses to bacterial infection**

## Overview

This project explores the transcriptional response of *Caenorhabditis elegans* to the pathogenic bacterium *Pseudomonas aeruginosa* PA14 using publicly available RNA-seq data. It combines gene-expression data organization with protein association network analysis to investigate candidate host-defense, stress-response, and regulatory mechanisms.

## Research Objective

To investigate how PA14 exposure is associated with gene-expression changes in *C. elegans* and explore the functional relationships among candidate genes and proteins.

## Dataset

- **GEO accession:** [GSE121091](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE121091)
- **Host:** *Caenorhabditis elegans*, wild-type N2
- **Pathogen:** *Pseudomonas aeruginosa* PA14
- **Control:** *Escherichia coli* OP50
- **Exposure:** 24 hours
- **Data type:** RNA sequencing (RNA-seq)
- **Biological replicates:** Three per condition

The dataset was generated by the original study and deposited in NCBI's Gene Expression Omnibus (GEO).

## Workflow and Tools

1. **Dataset organization:** Compiled gene-level data and organized the relevant experimental conditions.
2. **Expression analysis:** Examined gene-expression differences associated with PA14 exposure.
3. **Protein association analysis:** Used STRING to investigate functional connectivity among selected proteins.
4. **Network analysis:** Examined interaction scores, node degrees, and connected functional groups.
5. **Biological interpretation:** Related candidate genes and network patterns to host defense, cellular stress, and pathogen-response literature.

**Resources:** NCBI GEO, STRING, gene and functional annotations, and tabular data analysis.

## Key Findings

- **Network analysis:** Examined an 80-protein set using STRING and summarized its connectivity and functional groupings.
- **Network hubs:** *hsp-75*, *D1081.3*, *ddb-1*, and *skr-8* showed relatively high node degrees in the analyzed network.
- **Candidate functional themes:** Protein quality control, cuticle and extracellular matrix organization, and sensory-associated gene families emerged as areas for further investigation.
- **Interpretation:** These patterns provide hypotheses about host responses to bacterial exposure; network associations alone do not establish direct physical interactions or causal mechanisms.

For detailed findings, visualizations, and gene-level interpretations, see the [**Results**](https://github.com/tanishkaverma9289/C.elegans-PA14-infection-transcriptomics/blob/main/results/README.md) section.

## Reproducibility and Limitations

This repository documents an independent computational analysis of public data, not an original wet-lab experiment.

The interpretation of differential expression depends on the source and processing of the expression data, the statistical method, and the thresholds applied. STRING edges represent known or predicted protein associations and may reflect functional evidence rather than direct physical binding. Network centrality identifies highly connected nodes within the selected network, not necessarily experimentally validated regulatory hubs.

The repository includes compiled gene data, STRING network exports, and associated annotations to support transparency and interpretation. The analysis is based on publicly available data, and the findings should be interpreted in the context of the original study, database settings, and methodological limitations.
