# STRING Network Analysis

## Overview

This directory contains files associated with the STRING network analysis for the *Caenorhabditis elegans* PA14 infection project.

## Purpose

The network data are used to organize and explore relationships between genes or proteins relevant to the project.

## Data Documentation

The source, identifiers, interaction-confidence thresholds, and filtering criteria will be documented alongside the network files.

## Resource

[STRING Database](https://string-db.org/)
